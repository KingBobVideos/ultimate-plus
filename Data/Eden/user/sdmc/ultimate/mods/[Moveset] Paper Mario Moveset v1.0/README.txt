
Please ensure you have all below dependencies UP TO DATE!!

Smashline2 - https://github.com/HDR-Development/smashline

One Slot Effects - https://gamebanana.com/mods/549058


The new CSK Collection allows it so you dont need the CSS Manager to merge moveset mods.
However, if you have installed CSKs CSS Manager tool and would like to move where Paper Mario shows on your css, use the below details
Duplicate Olimar
Character ID: ui_chara_papermario (yes it is case sensitive)
Name ID: papermario (yes it is case sensitive)
Amount of Colors: 16
Color Start Index: 64
