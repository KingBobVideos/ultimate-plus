INSTALLATION:
This folder should go into sd:/ultimate/mods, so that the path "sd:/ultimate/mods/Goomba Moveset/plugin.nro" is valid. Goomba uses the "kuribo.marker" file for the plugin to determine how many alts Goomba has and which alts to use.

Like most Single Slot Movesets, you will need:
arcopolis, skyline, and nro hook (you most likely already have this)
smashline 2 (https://github.com/HDR-Development/smashline/releases)
the csk collection (https://gamebanana.com/mods/499008)
one slot effects (https://gamebanana.com/mods/549058)
param config (https://github.com/CSharpM7/lib_paramconfig/releases)

BEFORE YOU START:
On first boot, it is recommended to go to Vault > Tips > Fighters and select Goomba for information on how his specials and unique attacks work.

Note that since this is early access, some extra things are not included, but everything you'd need to play in a traditional competitive match should be there.
