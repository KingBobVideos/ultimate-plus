# Ultimate+

[Download Ultimate+ for Windows](https://github.com/KingBobVideos/ultimate-plus/releases/latest). The launcher downloads the modpack automatically on first run. Extract the whole folder into a writable location and drag your Smash Ultimate base-game XCI or NSP onto Play Ultimate+. Double-clicking also opens a file picker on first run. First run verifies and installs the pack inside Data/Eden/user/sdmc. Later launches open that exact game in portable Eden. Drag a new file onto the launcher to change the saved path. Set up your own Smash Ultimate 13.0.5, DLC, keys and firmware in this instance. Keep the folder together and use its launcher.

## Building another release

Use Python 3.11 or newer and run python installer/build.py VERSION with a fresh version name. The builder reads the sibling Ultimate Mod Lab installation. Only the emulator runtime and its notices are copied from Eden; the release starts with an empty portable user profile. Keep personal data out of distributed builds. Public release still needs a clean-PC gameplay test and a redistribution review, including Eden source availability.
